# English-Agent

AI 英语陪练助手。

## Getting Started

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Notes

- Baseline product specs live in `docs/superpowers/specs/`.
- The implementation plan lives in `docs/superpowers/plans/`.
- The app is scaffolded with Next.js, TypeScript, Tailwind CSS, and the App Router.
